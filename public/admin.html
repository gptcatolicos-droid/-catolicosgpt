💾 Persistencia & Recovery

Render.com tiene filesystem efímero: cada deploy borra el catálogo local. Cloudinary preserva las imágenes y su metadata. Usa este botón después de cada deploy para reconstruir el catálogo.

📘 Cómo persistir entre deploys (Render Disk)

Opción A (recomendada): En Render.com → tu service → Disks → Add Disk:

  • Name: catolicosgpt-data
  • Mount path: /data
  • Size: 1 GB (~$0.25/mes)

Luego agrega una env var:

DATA_DIR=/data

Opción B (gratis): Cada deploy: ejecuta este rebuild → recupera todo desde Cloudinary.
